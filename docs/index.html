ssh-copy-id

A cross-platform Zig implementation of ssh-copy-id(1) that uses your system ssh, ssh-add, and sftp commands and embeds remote key-installation scripts for POSIX sh, zsh, fish, PowerShell, cmd.exe, and NetScreen.

Install to PATH

Both installers verify SHA-256 checksums, work with or without administrative privileges, and look for an existing writable directory on your PATH without modifying shell configs or Windows PATH unless you pass --modify-path / -ModifyPath.

Searches PATH for an existing writable directory without modifying shell configs.

Privileges and PATH behavior

By default, install.sh and install.ps1 require no elevated privileges and never alter your shell profile or Windows environment variables. They scan PATH for an existing writable directory first, falling back to a standard user directory only if none is present.

Platform Mode Directory selection PATH modification
Linux / macOS / BSD Default / --user First writable directory in $PATH (e.g. ~/.local/bin, ~/bin, /opt/homebrew/bin), else ~/.local/bin None unless --modify-path is passed
Linux / macOS / BSD --system (uses sudo/doas if needed) /usr/local/bin/ssh-copy-id Already in system PATH
Windows Default / -Scope User Favors common directories in $env:Path (such as %LOCALAPPDATA%\Microsoft\WindowsApps, ~/.local/bin, ~/bin), then other writable user PATH dirs, else %LOCALAPPDATA%\Programs\ssh-copy-id\bin None unless -ModifyPath is passed
Windows -Scope Machine (Administrator) First writable directory in $env:Path, else %ProgramFiles%\ssh-copy-id\bin None unless -ModifyPath is passed

To override the directory or opt into updating PATH, pass --dir <path> or --modify-path to install.sh, or -InstallDir <path> / -ModifyPath to install.ps1.

Synopsis and options

ssh-copy-id [-h|-?|-f|-n|-s|-x] [-i [identity_file]] [-t target_path] [-F ssh_config] [[-o ssh_option] ...] [-p port] [user@]hostname
Flag Behavior
-i [identity_file] Install key(s) from identity_file (appends .pub if omitted), or newest ~/.ssh/id*.pub when file is omitted.
-f Forced mode: skip checking whether keys are already installed on the remote host.
-n Dry-run: print keys that would be installed without modifying the remote host.
-s SFTP mode: download, merge, and upload remote authorized_keys over sftp.
-x Debug trace: print executed ssh-add, ssh, and sftp commands to stderr.
-t target_path Remote authorized keys file path (default: .ssh/authorized_keys).
-p port Remote SSH/SFTP port.
-F ssh_config Pass an alternate SSH configuration file to ssh and sftp.
-o ssh_option Pass an SSH option to ssh and sftp (repeatable).
--remote-shell <s> Override remote shell detection (auto, sh, bash, zsh, fish, powershell, pwsh, cmd, netscreen).
--version Print embedded version string (e.g. ssh-copy-id 0.1.0) and exit.
-h, -?, --help Print option summary and exit.

Examples

ssh-copy-id user@example.com
ssh-copy-id -i ~/.ssh/id_ed25519.pub -p 2222 user@example.com
ssh-copy-id -n -i ~/.ssh/id_ed25519 user@example.com
ssh-copy-id --remote-shell powershell admin@win-host
